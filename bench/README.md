# Fluidum benchmarks

| | | checks | time |
|---|---|---|---|
| `bench_1p1d_viscous.jl` | the 1+1D viscous solver (`matrix1d_visc!`) against closed forms | **12** | ~25 s |
| `bench_2p1d_viscous.jl` | the 2+1D viscous solver (`matrix2d_visc!`) against closed forms | **19** | ~6 min |

Run from the package root:

```sh
julia --project=. bench/bench_1p1d_viscous.jl
FLUIDUM_1DV_FULL=1 julia --project=. bench/bench_1p1d_viscous.jl   # + N = 800 in A

julia --project=. bench/bench_2p1d_viscous.jl
FLUIDUM_2DV_FULL=1 julia --project=. bench/bench_2p1d_viscous.jl   # finer grids
```

Each prints one PASS/FAIL line per check and exits 1 if any check fails. Every reference is a closed
form or an ODE integrated inside the file; no data files are read.

## `bench_1p1d_viscous.jl`: the cylindrical solver

| section | what it checks |
|---|---|
| **M** | the two stored shear channels close onto a traceless, u-orthogonal `pi^{mu nu}`; at rest the largest characteristic is the MIS front `sqrt(c_s^2 + (4/3)eta/(w tau_pi) + zeta/(w tau_Pi))` to 6e-16; with viscosity off the extreme characteristics are the boosted sound cone to 1e-14; `A_t` conditioning over T = 0.05…0.6 GeV |
| **D** | `one_d_viscous_matrix_derived` (from `deriv/derive_2p1d_viscous.wls`) reproduces `one_d_viscous_matrix` entry by entry over 540 states (5.0e-15) |
| **B** | a radially uniform state integrates the 0+1D Israel–Stewart (+ `delta_pipi`) equations; `pi^phi_phi = -pi^eta_eta/2` follows from two independently evolved rows; uniformity and rest are fixed points; with viscosity off `tau*s` is conserved |
| **A** | a Woods–Saxon fireball reaches τ = 4 finite; `|u^r|` at the axis falls monotonically under refinement (1.0e-3 → 1.3e-4 over N = 100…400); T self-converges at observed order 1.03 |
| **C** | cost, not normalised per cell: the step count is not fixed across these grids, so a µs/cell figure would divide by the wrong thing |

Warm up before timing. Without a warm-up run the first size carries compilation and the cost looks
super-linear. With it, the three grids give about 4× the wall time for 4× the cells.

## `bench_2p1d_viscous.jl`: the transverse solver

| section | what it checks |
|---|---|
| **M** | the shear closure is traceless and u-orthogonal; rotational isotropy of the characteristic speeds; the Israel–Stewart front at rest is `sqrt(c_s^2 + (4/3) eta/(w tau_pi) + zeta/(w tau_Pi))` to 8e-16; the transverse shear channel is `sqrt(C_s)` independent of T and of the EoS; with viscosity off the extreme characteristics are the relativistic sound cone; the causal envelope, measured; `A_t` conditioning down to T = 0.02 GeV |
| **B** | a transversely uniform state integrates the 0+1D Israel–Stewart (+ `delta_pipi`) equations to 1e-10; this pins the conventions |
| **S** | the sound phase velocity and attenuation against the full MIS dispersion root; the excess damping is first order in `Δx`, the upwind scheme's own numerical viscosity, `D_num ≈ 0.75 Δx` |
| **G** | ideal Gubser evolved in 2-D, first-order convergence, x↔y symmetric to round-off |
| **A** | the 1-D and 2-D transport-coefficient paths agree; an axisymmetric 2-D viscous solve converges onto the 1-D cylindrical solver in all five fields; axisymmetry is preserved in the limit |
| **C** | cost |

### The two 2+1D matrices

`matrix2d_visc!` uses the matrix generated by `deriv/derive_2p1d_viscous.wls` by default
(`FLUIDUM_2D_DERIVED` unset or `1`). `FLUIDUM_2D_DERIVED=0` selects the legacy hand-written matrix,
whose `pi^{xy}` row is driven by the one-sided velocity gradient instead of its symmetric part. On
that matrix the transverse shear channel propagates at `sqrt(2 C_s)` along x and at 0 along y, and
**M2** (rotational isotropy) fails by 0.69 c. The derived matrix passes M2 at 2.8e-14. M2 runs both
and reports both.

## Checking an environment switch

Environment switches such as `FLUIDUM_2D_DERIVED` are read in `__init__`, so they take effect on
every load. A switch that silently does nothing and a change with no effect look the same in the
output, so before trusting a null comparison on an environment flag, check the value inside the
process:

```julia
julia -e 'using Fluidum; @show Fluidum.VISC_2D_DERIVED[]'                      # true  (the default)
FLUIDUM_2D_DERIVED=0 julia -e 'using Fluidum; @show Fluidum.VISC_2D_DERIVED[]' # false (the legacy matrix, + a warning)
```

M2 sets `F.VISC_2D_DERIVED[]` programmatically and restores it. `FLUIDUM_1DV_FULL` and
`FLUIDUM_2DV_FULL` are read by the scripts at run time.
